# Site Web Personnel - Portfolio

## Description du projet
Ce projet est un site web personnel (portfolio) conçu pour présenter le profil de deux étudiants en **Génie Informatique**. L'objectif est de fournir une plateforme vitrine regroupant nos informations personnelles, nos parcours académiques, nos compétences techniques ainsi qu'un moyen de nous contacter directement via un formulaire.

### Fonctionnalités principales :
* **Navigation fluide** : Utilisation de liens d'ancrage avec défilement doux (smooth scroll).
* **Présentation des profils** : Sections dédiées à Zakariya Aderdour et Marouane Berninz.
* **Section Compétences** : Affichage dynamique des technologies maîtrisées (HTML, CSS, C, JS).
* **Formulaire de contact** : Intégration avec FormSubmit pour l'envoi de messages réels.
* **Design Responsive** : Interface moderne et adaptée aux différents écrans.
* **Effets Interactifs** : Barre de navigation avec changement d'ombre au défilement.

## Technologies utilisées
* **HTML5** : Structure sémantique du site.
* **CSS3** : Mise en page (Grid/Flexbox), typographie (Google Fonts) et animations.
* **JavaScript (Vanilla)** : Gestion du défilement, manipulation dynamique du DOM pour les compétences et gestion de la soumission du formulaire.
* **Font Awesome** : Bibliothèque d'icônes pour les réseaux sociaux et les titres.
* **FormSubmit** : Service tiers pour la gestion des messages du formulaire de contact.
